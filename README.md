## 🚀 DEEP-SPACE PROJECT MISSIONS

### 🚆 01 — UK Railway Data Analysis & Business Intelligence

**SQL Server · Python · Power BI · Tableau**

An end-to-end analytics project transforming railway transaction data into operational and commercial insights.

- Architected a three-layer data warehouse using Bronze/Silver/Gold architecture.
- Engineered ETL workflows using Python and SQL stored procedures.
- Designed a star schema for analytical reporting.
- Built interactive dashboards for revenue, passenger demand, delays, and operational KPIs.
- Identified two routes generating **£296K in combined ticket revenue**, approximately 40% of total ticket revenue in the analyzed dataset.
- Found that six of 65 routes accounted for 75% of passenger traffic.

### 🎵 02 — Spotify Analytics Dashboard

**Python · Plotly Dash · Pandas · NumPy**

An interactive exploration of music trends, popularity, and audio characteristics across more than two decades.

- Analyzed **54,000+ tracks from 2000–2023**.
- Performed data cleaning, feature engineering, and metadata enrichment.
- Integrated external Spotify metadata using track IDs.
- Created interactive visualizations for genres, popularity trends, audio features, and time-series insights.

### ♻️ 03 — Waste Classifier: Intelligent Recycling System

**Python · PyTorch · Deep Learning · Computer Vision**

An AI-powered image classification project designed to support intelligent waste sorting.

- Classified waste into five categories: Plastic, Paper, Metal, Glass, and Organic.
- Benchmarked CNNs, ResNet50, EfficientNetB3, transfer learning, and Vision Transformers.
- Built a data pipeline with image scraping, duplicate removal, and data augmentation.
- Evaluated model performance using precision, recall, F1-score, confusion matrices, Grad-CAM, and attention visualizations.
