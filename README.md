## 🚀 Featured Projects

### 🚆 UK Railway Data Analysis & Business Intelligence

**SQL Server · Python · Power BI · Tableau**

- Designed a three-layer data warehouse using Bronze, Silver, and Gold architecture.
- Built ETL pipelines and transformed raw data into an analytical star schema.
- Developed SQL analytical queries and time-series forecasting models.
- Created interactive dashboards to analyze revenue, passenger demand, delays, and operational performance.
- Identified two routes generating **£296K in combined ticket revenue**, representing approximately 40% of total ticket revenue in the analyzed dataset.
- Found that six of 65 routes accounted for 75% of passenger traffic.

### 🎵 Spotify Analytics Dashboard

**Python · Plotly Dash · Pandas · NumPy**

- Built an interactive dashboard analyzing **54,000+ tracks from 2000–2023**.
- Performed data cleaning, feature engineering, and metadata enrichment.
- Integrated external Spotify metadata using track IDs.
- Explored genre distributions, popularity trends, audio features, and changes over time.

### ♻️ Waste Classifier — Intelligent Recycling System

**Python · PyTorch · Deep Learning · Computer Vision**

- Developed an image classification system for five waste categories: Plastic, Paper, Metal, Glass, and Organic.
- Benchmarked CNN architectures, transfer learning models, ResNet50, EfficientNetB3, and Vision Transformers.
- Built a data preparation pipeline involving image scraping, duplicate removal, and data augmentation.
- Evaluated models using precision, recall, F1-score, confusion matrices, Grad-CAM, and attention visualizations.
