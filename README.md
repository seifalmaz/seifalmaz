## Deep-Space Missions

### Mission 01: UK Railway Data Analysis & Business Intelligence

<img src="https://img.shields.io/badge/SQL_Server-CC2927?style=flat-square&logo=microsoftsqlserver&logoColor=white" alt="SQL Server"/>
<img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white" alt="Python"/>
<img src="https://img.shields.io/badge/Power_BI-F2C811?style=flat-square&logo=powerbi&logoColor=black" alt="Power BI"/>
<img src="https://img.shields.io/badge/Tableau-E97627?style=flat-square&logo=tableau&logoColor=white" alt="Tableau"/>

An end-to-end analytics project turning railway transaction data into operational and commercial insights.

- Architected a three-layer data warehouse using Bronze/Silver/Gold architecture.
- Engineered ETL workflows with Python and SQL stored procedures, feeding a star schema for reporting.
- Built interactive dashboards for revenue, passenger demand, delays, and operational KPIs.
- **Result:** two routes generated **£296K in combined ticket revenue**, about 40% of the total in the analyzed dataset.
- **Result:** six of 65 routes accounted for 75% of passenger traffic.

### Mission 02: Spotify Analytics Dashboard

<img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white" alt="Python"/>
<img src="https://img.shields.io/badge/Plotly_Dash-3F4F75?style=flat-square&logo=plotly&logoColor=white" alt="Plotly Dash"/>
<img src="https://img.shields.io/badge/Pandas-150458?style=flat-square&logo=pandas&logoColor=white" alt="Pandas"/>
<img src="https://img.shields.io/badge/NumPy-013243?style=flat-square&logo=numpy&logoColor=white" alt="NumPy"/>

An interactive exploration of music trends, popularity, and audio characteristics across more than two decades.

- Analyzed **54,000+ tracks from 2000–2023**.
- Cleaned data, engineered features, and enriched records with external Spotify metadata via track IDs.
- Built interactive visualizations for genres, popularity trends, audio features, and time-series patterns.

### Mission 03: Waste Classifier, Intelligent Recycling System

<img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white" alt="Python"/>
<img src="https://img.shields.io/badge/PyTorch-EE4C2C?style=flat-square&logo=pytorch&logoColor=white" alt="PyTorch"/>
<img src="https://img.shields.io/badge/Computer_Vision-312E81?style=flat-square" alt="Computer Vision"/>
<img src="https://img.shields.io/badge/Deep_Learning-0891B2?style=flat-square" alt="Deep Learning"/>

An image classification system for waste sorting across five classes: Plastic, Paper, Metal, Glass, and Organic.

- Benchmarked CNNs, ResNet50, EfficientNetB3, transfer learning, and Vision Transformers.
- Built a data pipeline with image scraping, duplicate removal, and augmentation.
- Evaluated with precision, recall, F1-score, confusion matrices, Grad-CAM, and attention visualizations.
